Suno GMVP Prompt Generator — V1

Contenu:
- index.html : interface de l'application
- app.js : logique, base de suggestions, générateur, sauvegarde/historique
- style.css : design responsive

Utilisation:
1. Décompresser le ZIP.
2. Ouvrir index.html dans un navigateur moderne.
3. Remplir la configuration.
4. Construire la structure et sélectionner les métatags.
5. Cliquer sur « Générer le prompt ».

Fonctions ajoutées dans cette V1:
- sauvegarde locale automatique
- bouton Sauvegarder
- historique des projets
- import/export JSON
- réinitialisation
- interface sans dépendance serveur
