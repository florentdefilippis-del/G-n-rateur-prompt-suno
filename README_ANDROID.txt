SUNO GMVP STUDIO — VERSION WEB MOBILE

Cette version contient un index.html autonome : le CSS et le JavaScript sont intégrés directement dans la page.
Elle est conçue pour être ouverte directement depuis un téléphone Android, même lorsque le gestionnaire de fichiers utilise file://.

UTILISATION
1. Décompresser le ZIP.
2. Ouvrir index.html avec Chrome ou un navigateur compatible.
3. Si le navigateur propose « Ajouter à l'écran d'accueil », utiliser cette option.

Cette édition ne dépend pas du chargement de style.css ou app.js pour l'affichage initial.
